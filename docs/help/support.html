FAQ — English

  • Screen Recording permission — System Settings → Privacy & Security → Screen Recording → enable ScreenVoiceRec, then restart the app.
  • Microphone permission — Required only for “3.5 mm Headphone Jack / Line In”. Enable in System Settings → Privacy & Security → Microphone.
  • No audio in recording — Confirm the level meter moves before recording; check source volume and the correct window or display is selected.
  • Where are files saved? — In the app’s Recordings folder (shown in the Save Location section). Use Open Recordings Folder in the app.
  • Supported formats — AAC (M4A), Apple Lossless (M4A), FLAC (CAF), WAV.

FAQ — Français

  • Autorisation d’enregistrement d’écran — Réglages système → Confidentialité et sécurité → Enregistrement de l’écran → activez ScreenVoiceRec, puis relancez l’app.
  • Autorisation micro — Requise uniquement pour « Prise casque 3,5 mm / entrée ligne ». Activez dans Réglages système → Confidentialité et sécurité → Microphone.
  • Pas d’audio dans l’enregistrement — Vérifiez que l’indicateur de niveau bouge ; contrôlez le volume et la bonne fenêtre ou écran.
  • Où sont les fichiers ? — Dans le dossier Enregistrements de l’app (section Emplacement). Utilisez Ouvrir le dossier d’enregistrements.
  • Formats pris en charge — AAC (M4A), Apple Lossless (M4A), FLAC (CAF), WAV.
